# OKYS – Online Kütüphane Yönetim Sistemi

YBS203 Nesneye Yönelik Programlama – Uygulama 2 (Class ve Object, UML).

## İçerik
- `doc/okys-DESIGN.drawio` – Use Case ve Class diyagramları (draw.io), `okys-usecase.png`, `okys-class.png`
- `doc/okys-SRS.md` – Gereksinim özeti
- `src/` – Java kodları: Kullanici, Uye, KutuphaneGorevlisi, Kitap, KitapKopyasi, OduncKaydi, Main

## Çalıştırma

cd src
javac *.java
java Main
